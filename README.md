# ChatGPT Pro Exporter

Эта репозитория содержит исходники расширения Chrome/Edge (Manifest V3) для экспорта диалогов ChatGPT в DOCX и PDF с профессиональным оформлением: шрифты офисного уровня, таблицы, списки, аккуратный код и рендер LaTeX формул через KaTeX.

## Быстрый старт
1. Откройте каталог `extension` – внутри уже готовый манифест, контент-скрипт и подключенные библиотеки.
2. В Chrome или Edge включите «Режим разработчика» в `chrome://extensions/` / `edge://extensions/`.
3. Выберите «Загрузить распакованное расширение» и укажите путь к папке `extension`.
4. Перейдите на `https://chat.openai.com` или `https://chatgpt.com` – внизу справа появится панель экспорта.

## Как работает
- Контент-скрипт добавляет плавающую панель с кнопками **DOCX** и **PDF**.
- Для DOCX используется `html-docx-js`: сохраняет семантику заголовков, списков, таблиц и кода, оставляя документ редактируемым.
- Для PDF используется `jsPDF` + `html2canvas` для точного рендеринга макета.
- Формулы, записанные как `$...$` или `$$...$$`, автоматически рендерятся KaTeX перед экспортом, чтобы в итоговых файлах формулы выглядели профессионально.

Подробная инструкция — в [extension/README.md](extension/README.md).
